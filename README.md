# Егор Хаймусов — сайт-портфолио

Светлый адаптивный сайт-резюме на HTML/CSS/JavaScript для GitHub Pages.

## Содержание
- index.html — весь сайт (HTML + CSS + немного JavaScript).
- favicon.svg — иконка вкладки.
- .nojekyll — отключает Jekyll.

## Опубликовать на GitHub Pages
1. Откройте Settings → Pages в репозитории haymuzz/MyProjects---DataAnalyst.
2. Build and deployment → Source: Deploy from a branch.
3. Branch: gh-pages; Folder: /(root).
4. Нажмите Save.

После завершения публикации адрес будет:
https://haymuzz.github.io/MyProjects---DataAnalyst/

Это отдельная ветка gh-pages. Основная ветка main с аналитическими проектами не менялась.

## Короткий адрес
Для адреса https://haymuzz.github.io нужно создать отдельный публичный репозиторий haymuzz.github.io и загрузить в корень эти файлы, а затем включить Pages для main и /(root).
